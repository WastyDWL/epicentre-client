# Epicentre Client — дизайн форка NextClient

Дата: 2026-11-02. Основа: NextClient (форк `WastyDWL/epicentre-client`, ветка `epicentre`).
Лицензия исходного репозитория не указана — решение о выпуске форка принял владелец проекта.

## Зачем

Клиент CS 1.6 под сервер **Эпицентр Арена Страйка** (45.95.31.157:27115, epicentre-cs.ru):
игрок запускает игру и одним нажатием «Подключиться» попадает на сервер. Меню — современная
веб-страница в стиле Эпицентра; общий мастер-лист остаётся, сайт доступен прямо из меню.

## Цели

1. Своё главное меню (HTML, `assets/platform/epicentre/menu`):
   - главная: карточка сервера Эпицентра (онлайн, карта, игроки) и кнопка «Подключиться»;
   - «Серверы»: общий мастер-лист + избранное + история, сервер Эпицентра закреплён первым;
   - «Сайт»: epicentre-cs.ru целиком (сайт запрещает фреймы → открывается в окне меню
     с кнопкой «← В меню»).
2. Встроенный Chromium 150 вместо CEF1 для всех HTML-окон (MOTD, меню, всплывающие окна):
   собственный `chromehtml.dll`, реализующий `ChromeHTML_Controller_001`. CEF1 удаляется.
3. Полный `window.nextclient` в новом движке, включая `matchmaking.*` и новый
   `matchmaking.getInternetServers()` для мастер-листа.
4. Брендинг: название, иконки, заголовок окна, тексты — «Эпицентр».

## Не-цели

- Свой античит, свой мастер-сервер, своя система обновлений (на первом этапе).
- Linux-сборка клиента с новым браузером (CEF-часть только Windows, как и у NextClient).

## Анти-цели

- Сломать то, что работает в NextClient: настройки, радар, материалы, сервер-браузер vgui.
- Пускать привилегированный API (`exec`) для чужих сайтов.

## Как устроено

### chromehtml.dll (новый модуль `nextclient/chromehtml`)
- Переносится ядро мода nextchromium (Engine/Browser/FrameBuffer/вход/навигация/ncb://api),
  без перехватчиков: `CreateInterface("ChromeHTML_Controller_001")` отдаёт `NcController`,
  `CreateSerializer` — `NcSerializer` (честная реализация `IHTMLSerializer`).
- CEF 150 лежит в `<игра>\cef\` и подгружается по полному пути (delay-load): при установке
  поверх NextClient в корне может остаться старый `libcef.dll`.
- JS-API: `ncb://api/<method>` (только XHR/fetch), обработчики регистрируются модулями через
  интерфейс `NCL_BrowserApi_001` (метод → обработчик с асинхронным ответом; рассылка событий).
  Встроенные обработчики (cvar, connectedHost, gameUi, exec) — из мода, остальное отдаёт GameUI.

### GameUI / engine_mini
- Регистрации `CefRegisterExtension` (CEF1) переписываются на `NCL_BrowserApi_001`;
  зависимость от CEF1 `libcef.dll` убирается.
- `MainMenuBrowser`: если нет `platform\mmb_home_page.html`, открывает встроенное меню
  `ncl://menu/index.html` (файлы из `platform\epicentre\menu`), это происхождение доверенное.
- `matchmaking.getInternetServers()` — через тот же сервис мастер-листа, что и vgui-браузер серверов.

### Меню и сайт
- Меню открывается в браузере главного меню (user agent содержит «Main Menu Browser»); на чужих
  страницах в этом браузере bootstrap показывает кнопку «← В меню».
- `platform\accepted_domains.txt` содержит `epicentre-cs.ru`.

## Решения, принятые исполнителем
- Название в коде/путях: `epicentre`; продукт: «Epicentre Client» / «Эпицентр».
- CEF в подпапке `cef\`, вспомогательный процесс `cef\ncb_subprocess.exe`.
- Меню поставляется в клиенте (работает без интернета); сайт открывается онлайн.
- Сборка на Windows: `tools\build-windows.cmd` (ninja-пресет, vcvars32, загрузка vcpkg через
  `tools\vcpkg-fetch.ps1` из-за прокси).
