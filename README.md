# Epicentre Client

Клиент Counter-Strike 1.6 сервера **Эпицентр Арена Страйка** — `45.95.31.157:27115`.
Сайт: [epicentre-cs.ru](https://epicentre-cs.ru) · Группа: [vk.ru/arenatira](https://vk.ru/arenatira)

Запускаете игру и попадаете в меню Эпицентра: онлайн сервера, карта, список игроков и кнопка **«Подключиться»**. Общий мастер-лист серверов тоже остаётся.

Основа — [NextClient](https://github.com/CS-NextClient/NextClient) (описание оригинала: [NEXTCLIENT.ru.md](NEXTCLIENT.ru.md) · [EN](NEXTCLIENT.md)).

**[Последний релиз →](https://github.com/WastyDWL/epicentre-client/releases/latest)**, файл `EpicentreClient-v*.zip`.

## Возможности

- **Своё главное меню во весь экран.** Это веб-страница в стиле Эпицентра. На ней:
  - карточка сервера с онлайном, картой и игроками;
  - кнопка «Подключиться»;
  - ссылки на сайт и группу ВКонтакте.
- **Серверы.** Есть три списка:
  - общий мастер-лист;
  - избранное (★, можно добавить сервер по адресу);
  - история.

  Сервер Эпицентра закреплён первым. Есть поиск, фильтры («Не пустые», «Есть места», «Без пароля», «Без ботов»), пинг и кнопка «Обновить». Список появляется по мере ответа серверов.
- **Меню игры в верхней навигации.** Вне игры там «Новая игра», «Настройки» и «Выход». В игре — «▶ В игру», «Игроки», «Отключиться», «Настройки» и «Выход». Стандартное меню и окно серверов при запуске не появляются.
- **Chromium 150 вместо встроенного Chromium 18 (2012 год).** MOTD и сайты отображаются как в обычном браузере: современная вёрстка, CSS и JavaScript работают.
- **Своё оформление.** Заголовок окна «Эпицентр Арена Страйка» и иконка Эпицентра. Статуса в Discord нет.

## Установка

1. Нужна **Steam-версия Counter-Strike 1.6** и **запущенный Steam**.
2. Сделайте копию папки игры, потому что клиент заменяет `cstrike.exe` и модули NextClient.
3. Распакуйте архив в корень папки игры (там, где `hl.exe`) с заменой файлов.
4. Запустите `cstrike.exe`.

> Официальный лаунчер NextClient при запуске обновляется и перезаписывает файлы этого клиента. Не запускайте его в той же папке.

## Для разработчиков

- **Меню.** Обычные HTML, CSS и JS в [`assets/platform/epicentre/menu`](assets/platform/epicentre/menu). В игре меню открывается по адресу `ncl://menu/index.html`. Вне игры страницу можно открыть в браузере, тогда она покажет примерные данные.
- **Браузер.** Модуль [`nextclient/chromehtml`](nextclient/chromehtml): CEF 150 и JS-API `window.nextclient`.
- **Сборка (Windows):**
  ```bat
  tools\build-windows.cmd Release "C:\Games\CS 1.6 - Epicentre"
  ```
- **Подробнее** — о том, чем форк отличается от NextClient, и о сборке: [docs/epicentre/README.md](docs/epicentre/README.md). Решения по дизайну: [docs/epicentre/2026-11-02-design.md](docs/epicentre/2026-11-02-design.md).
